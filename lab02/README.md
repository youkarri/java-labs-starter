## Инварианты `DataSample`

1. `id` не равен `null` и не пуст (строка из одних пробелов тоже считается пустой).
2. `label` не равен `null` и не пуст.
3. `status` не равен `null`.
4. `features` не равен `null`, не пуст и содержит только конечные числа (без `NaN` и бесконечностей).
5. Массив признаков копируется в конструкторе и при возврате из `getFeatures()`, поэтому состояние нельзя изменить снаружи.
6. Статус меняется только методом `changeStatus`, который не принимает `null`.
7. `id`, `label`, `features` не меняются после создания: setter-ов нет, поля `final`.

## Инварианты `BankAccount` (подготовительная часть)

1. Баланс никогда не отрицательный.
2. `deposit` принимает только положительную сумму.
3. `withdraw` принимает только положительную сумму, не превышающую остаток.
